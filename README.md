總管家包租代管 - 修繕報告自動化工具

這是一款專為 總管家包租代管 團隊設計的輕量化網頁工具。旨在解決外勤人員在修繕現場需要快速整理紀錄、排列照片並產出專業 Word 報告的需求。

🌟 核心特色

純瀏覽器運行：無需安裝任何軟體或 App，直接打開 HTML 檔案即可使用。

手機適配優化：針對行動裝置設計，支援現場拍攝並直接上傳。

照片管理系統：

即時預覽：上傳後立即顯示小圖。

快速刪除：發現拍錯可單張刪除，不需全部重傳。

圖片標準化引擎 (Auto-Normalization)：

自動將 iPhone 的 HEIC 或巨型圖檔轉為標準 JPEG。

解決 Word 檔案常見的「圖片處理異常」或「照片消失」問題。

自動等比例縮放，確保不變形且檔案體積輕量化。

一鍵導出 Word：

自動套用「最窄邊距」設定。

照片採「一列兩張」整齊排列。

地址置頂，版面簡潔美觀。

🚀 快速上手

方式一：本機執行 (最推薦)

下載 repair_report_generator.html 到您的電腦或手機。

使用 Chrome、Edge 或 Safari 瀏覽器打開檔案。

方式二：GitHub Pages 部署

將檔案上傳至您的 GitHub 儲存庫。

開啟 Settings > Pages 功能，即可獲得一個專屬的網址，發給全公司同仁使用。

🛠 操作流程

輸入地址：於頂部欄位輸入修繕標的地址。

填寫紀錄：

分為「修繕前、修繕中、修繕後」三個階段。

在文字框輸入原因或說明。

上傳照片：

點擊「選擇照片」按鈕，可多選上傳。

透過小縮圖確認內容，點擊紅色的 ✕ 可移除錯誤照片。

預覽與下載：

點擊「即時預覽」確認排版。

點擊「下載 Word 檔案」即可獲得專業報表。

📦 技術規格

前端框架：Tailwind CSS (UI 美化)

Word 引擎：docx.js (UMD 版本)

檔案處理：FileSaver.js

圖片引擎：HTML5 Canvas API (用於格式轉換與等比縮放)
